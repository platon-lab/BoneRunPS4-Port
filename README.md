# Bone Run: игра про Тито для PS4 (GoldHEN)

## Что внутри
- src/game.c: логика игры (прыжки, кости, жизни, очки, рестарт). Тестируется на ПК.
- src/main_ps4.c: платформенный слой для PS4. Вывод на экран и пэд - TODO.
- tests/test_game.c: автотесты, включая длинный прогон без падений.
- Makefile: make test, make ps4, make package.
- .github/workflows/build.yml: GitHub Actions. Тесты, затем сборка, затем zip.
- assets/tito.png: твой спрайт.

## Что проверено
- Логика игры компилируется с -Wall -Wextra -Werror и проходит тесты (make test).

## Что НЕ проверено (нужно сделать на твоей стороне)
1. Вывод на экран и пэд. Заполни TODO в main_ps4.c кодом из официальных примеров OpenOrbis.
2. Флаги линковки в Makefile. Скопируй их из примеров toolchain.
3. param.sfo и icon0.png. Без param.sfo PKG не встанет в библиотеку.
4. Упаковка в PKG. Инструмент для PKG зависит от версии toolchain, его нужно выбрать отдельно.
5. Совместимость с прошивкой. Проверь в релизе GoldHEN список поддерживаемых прошивок, есть ли там 14.00. Если нет, PKG не запустится, как бы он ни был собран.

## Как запустить
1. Залей папку в репозиторий GitHub.
2. Открой вкладку Actions и запусти Build Bone Run.
3. Скачай артефакт bone-run-ps4 (zip).
4. Если сборка упала, пришли мне лог шага, где ошибка.
